# Calculator Projects

A beginner-friendly web technology project containing a Simple Calculator and a Scientific Calculator, built with HTML, CSS, and JavaScript.

## Files

- `index.html`, `style.css`, `script.js` — Simple Calculator
- `scientific.html`, `scientific.css`, `scientific.js` — Scientific Calculator

## How to run

1. Download or extract this folder.
2. Open `index.html` in a web browser to use the Simple Calculator.
3. Open `scientific.html` to use the Scientific Calculator.
4. No installation or internet connection is required.

## Features

### Simple Calculator
- Addition, subtraction, multiplication, and division
- Percentage, decimal values, clear, and delete
- Keyboard support

### Scientific Calculator
- Basic arithmetic
- Square root, square, powers, percentage
- Sine, cosine, tangent, logarithm (log), and natural logarithm (ln)
- Pi and Euler's number
- Degree/radian angle mode
- Keyboard support
